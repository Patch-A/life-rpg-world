# 角色体验室 · 第一版

访问 `/character-lab`。独立样板，不读写正式存档、不触发真实经验与奖励；刷新恢复初始状态。`/art-lab` 增加了入口。

## 已实现

- 男、女两位探索者，各有探索装与正式服装，共四张透明角色立绘。
- 点击人物或打招呼按钮，循环显示鼓励语；场景小幅视差、轻微待机动效。
- 全身 / 近景切换。
- 完成模拟任务，经验由 60 变为 80，显示徽章与短暂庆祝；重复动作不会重复奖励。
- 每位角色独立开启生日礼物，解锁对应礼服。未解锁礼服会引导打开礼物，领取后可反复换装。
- 角色切换保留各自穿戴状态；重置统一恢复。原始存档完全独立。
- 尊重系统减少动态设置，页面隐藏暂停动效；提供手动动效开关。
- 保留独立 3D 道具工坊链接，不在角色样板中加载 Three.js。

## 当前边界

不是骨骼动画，不提供真实 360°转身、自然挥手或眨眼；衣服是整套立绘切换，不是任意单件组合。已做类型、状态逻辑与构建检查，未做浏览器/手机实测。

内置图像生成工具制作，WebP 转码保留透明通道。每张 768×1152，大小约 105–190 KB。人物剪影与透明背景已在同色底预览中目视检查，未使用缺陷 3D 模型的截图替代新立绘。

生成提示词共同部分：以已确认的男女面部稿分别保持男性/女性身份，精致半写实游戏立绘，一个完整人物、头发至鞋全部可见、直立自然姿势、正面看向观众、干净透明背景、柔和统一光线，不添加文字、边框、场景或地面阴影。

## 后续验收顺序

先验收角色脸型与衣服一致性、手机近景/全身构图、点击和换装触发，再接入主游戏角色位、衣柜、生日与里程碑事件。接入时复用正式奖励判断，不能将本样板的模拟状态作为正式奖励来源。

## V11 正式角色和道具规则

正式游戏共享 2D 角色组件，覆盖首次选择、角色设置、顶栏头像、个人档案、衣柜和生日仪式。角色形象与性别统一：男角色只能穿男款探索装与星光西装，女角色只能穿女款探索装与月光礼裙。衣柜过滤、后端 equip 校验、渲染素材选择使用统一适配判断。成人礼提示按角色显示对应服装；角色设置取消独立选择另一性别形象的入口。

读取旧存档时修复不匹配的形象和装备：成人礼已解锁则转换到对应性别礼装，否则退回探索装。变更角色同样转换装备，已保存的日志、经验、生日纪念、里程碑、照片与领取记录不变。修复后的存档在下次正常保存时持久化，读取时已返回修正后的展示状态。没有批量改写玩家数据。

男穿礼裙、女穿西装的两套新增素材已移除。独立角色体验室仍使用男西装、女礼裙的样例；其中生日开礼物是模拟，不写正式存档。正式游戏的礼装由18岁成人礼解锁，生日纪念章、工作徽章及其他通用纪念按原条件获得，不受服装适用性影响。

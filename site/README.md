# 人生 RPG · 成长星球

一个手机优先的个人成长 RPG：把现实中的学习、工作、运动、关系和储蓄等小行动，转化为可追踪的经验、主线进度与探索节点。

## 产品边界

- 现实成长为主：只有记录真实完成的行动，才会推进目标和结算经验。
- 虚拟探索为辅：人生星球、地图节点、奇遇与勋章提供持续反馈，但不会把虚构事件写入现实记录。
- 第一版不读取支付宝消费、步数或其他敏感数据，采用手动记录；后续进入支付宝时再按授权能力接入。
- 每个用户拥有独立云端存档；私密 Sites 访问由平台身份认证保护。

## 已实现

- 手机优先的四入口：世界、任务、成长、我的
- 初次创建探索者、成长方向和第一条主线
- 主线目标：累计目标、单位、截止日期、暂停与恢复、进度条
- 行动清单：每日行动、支线行动、目标关联、归档、已完成筛选
- 记录流程：数值校验、重复领奖防护、完成时 +30 EXP
- 经验与等级：每 200 EXP 升一级；撤销记录后重算经验和进度
- 人生地图：五个成长领域、解锁节点、技能树、行动足迹
- 角色页：等级、统计、勋章、冒险日志、导出存档、减少动态效果
- 三段虚拟奇遇，选择只产生冒险纪念，不影响现实数据
- D1 云端持久化、乐观并发检查、错误提示和可恢复状态
- WebMCP 只读进度查询与页面导航工具（浏览器支持时启用）

## 本地开发

要求 Node.js `>=22.13.0`。

```bash
pnpm install
pnpm run db:generate
pnpm run build
```

本项目使用 Cloudflare D1，逻辑绑定名为 `DB`。本地预览需要先按 Sites 文档生成 `dist/server/wrangler.json`，再应用 `drizzle/0000_zippy_monster_badoon.sql`。部署时由 Sites 自动应用生产迁移。

## 支付宝路线

建议以支付宝小程序原生壳承载 H5 或逐步迁移核心页面。需要单独完成：备案域名、H5 白名单、支付宝授权边界、隐私说明、真机性能测试以及真实数据 API 的合规授权。本仓库当前不伪造支付宝数据，也不在前端保存敏感凭据。

## 目录

- `app/page.tsx`：核心交互页面与状态反馈
- `app/api/game/route.ts`：存档读写与并发保护
- `lib/game.ts`：游戏状态、规则与事件 reducer
- `db/schema.ts`：D1 存档表
- `public/world.webp`、`public/explorer.webp`：人生星球与探索者视觉资产
- `drizzle/`：数据库迁移

## 隐私与安全

不要提交 `.env`、访问令牌、个人存档导出文件或真实支付宝授权信息。当前存档以 Sites 注入的用户 ID 隔离，客户端无法指定其他用户的存档 ID。

## 开源状态

源码已按可开源结构整理。创建对应的 GitHub 空仓库后，可直接推送当前 `main` 分支；Sites 部署源与公开 GitHub 仓库可以保持独立。

## 第二版：个人成长核心

- 默认进入“今天”，四个主入口为今天、目标、世界、我的；原成长地图仍可从世界进入。
- 记录发生日期、录入日期、数值、说明与最多三张私密照片；按北京时间累计。
- 运动等分钟任务可使用暂停/继续的应用内计时，或手动补录。计时不作为行为真实性认证。
- 支持超过每日目标继续记录；同一领域、同一天最多结算30经验，拆分记录或创建同类行动不能刷经验。
- 存钱目标支持已有余额、逐笔存入/取出、月度净变化。记账模式在有记录后锁定；月度再次提交更新同月条目，不重复累计。
- 修改记录保留历史；撤销保留原条目并重算目标及经验。已取出款项时不能撤销导致净存款为负的存入记录。
- 成人礼、第一份工作、第一次工资、毕业与自定义纪念均可补录。首次奖励独立于事件日期，以持久化领取标记去重，归档和恢复不会重领。
- 成人礼解锁星光西装、月光礼裙，可自由选择，不按性别限制；第一份工作、第一次工资与毕业解锁对应徽章。
- 可关闭成长庆祝；没有主动分享入口，文本、照片和财务信息均默认私密。
- 支持JSON结构化存档和完整离线HTML纪念册，后者内嵌文字、照片、日期、历史记录。
- 上传前在浏览器压缩为JPEG并移除原始EXIF；R2保存图片，D1保存照片所有者。照片读取和记录关联都在服务端验证所有权。
- 断网/失败时保留输入；未提交表单仅作为该设备的临时sessionStorage草稿，不作为正式存档。

验证：`node scripts/verify-growth.mjs` 和 `node node_modules/typescript/bin/tsc --noEmit`。

### 后续接入边界

`lib/identity.ts`集中处理可信身份来源；`lib/game.ts`为不依赖Sites或支付宝的成长规则。未来支付宝端需要独立验证用户身份并映射到应用用户，再共用记录与成长服务。当前没有完成支付宝授权、个人主体能力审核、步数同步或小程序上线；不能把已有网站当成已接入的小程序。

第二阶段仍待开发：应用内好友、双人挑战、承诺卡与双方兑现确认。GitHub上传按用户要求暂缓。

### 角色视觉资产

基础星球与探索者延续第一版。两套成年礼装使用内置imagegen生成、保留alpha透明通道，位于`public/outfit-suit.png`、`public/outfit-dress.png`。提示词为：同一暖棕眼、卷棕发、友善3D探索者，完整站立姿态，分别穿海军蓝紫色银饰西装／淡紫银饰长礼裙，无文字、界面或水印。服装仅改变装饰，不改变真实记录或经验。


### 个人纪念与生日（第二次个人版优化）

- 首次“回顾我的人生”可跳过；从“我的”持续进入。里程碑支持具体日期、只记年份、日期不详，保留录入时间与修改历史。年龄不推断毕业或就业经历。
- 生日默认公历，可切换农历。出生年份选填，默认隐藏年龄、数据私密。计算固定使用Asia/Shanghai。
- 农历闰月可选择每年普通月份庆祝，或只在对应闰月出现时庆祝；三十遇到小月可选廿九或次月初一。公历2月29日的非闰年规则可选2月28日或3月1日。
- 换算使用Intl Chinese Calendar，不用固定加减天数或未核验的农历表。官方校验资料：[香港天文台2025历表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2025e.pdf)、[2026历表](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2026e.pdf)；运行时依据：[Cloudflare Intl支持](https://developers.cloudflare.com/workers/runtime-apis/web-standards/#intl)、[MDN formatToParts](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/formatToParts)。不支持Chinese Calendar的设备明确提示，不静默替换为公历。
- 当年生日已过的晚加入用户可补过；加入后错过的生日跨年保留入口，首页只提示最近一次，可关闭首页提示。生日不增加经验，每个公历年度一枚星球生日纪念章，跨日历切换或删除纪念不会重复发奖。农历纪念同时显示农历年份与实际公历日期。
- 庆祝由用户点击开始，可跳过、安静保存或重看。纪念支持感受、照片、给下一岁的留言、上一份留言回看、过去一年实际记录摘要；不生成未记录的成果。
- 生日前设置只在站内提示，未包含系统推送、微信/短信通知或好友祝福。
- 纪念可归档恢复或永久删除文字/历史；奖励领取标记保留。照片管理可清理草稿照片或永久删除文件，并从行动、里程碑、生日全部移除。删除先用D1条件更新与事务标记隐藏，R2失败保留可重试清理条目；永久删除操作有明确确认。旧离线导出副本由用户自行保管。
- JSON导出版本3，完整HTML纪念册新增生日与模糊日期；文本转义防止用户内容变成脚本。

验证：`node scripts/verify-growth.mjs`、`node --disable-warning=ExperimentalWarning scripts/verify-api.mjs`、`node scripts/verify-birthday.mjs`、`node scripts/verify-memories-ui.mjs`、`node scripts/verify-calendar-runtime.mjs`、TypeScript检查与正式构建。API测试使用隔离SQLite/R2模拟，日历另在本地workerd运行时校验；组件渲染检查不等同于真实手机浏览器验收，移动端逐页实际操作仍待完成。

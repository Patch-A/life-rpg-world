# 本地运行

1. 下载Release中的 `life-rpg-h5-submission-v0.2.zip`，解压进入life-rpg-h5/，不要用自动生成的Git仓库Source code ZIP替代。
2. 安装Node.js24及pnpm11.25.0，执行：

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm build
node start-local.mjs
```

3. 打开 `http://127.0.0.1:3187`。首次启动生成 `data/local-preview-invitation.json`，复制其中的 `invitationCode` 登录。每位下载者生成自己的账号，无需作者提供邀请码。
4. 创建角色并确认成年试用，生日/照片可跳过。默认AI关闭；/demo是明确标注的固定虚构样例。
5. 若要真实AI，在本人可控、被Git忽略的测试配置文件填写DEEPSEEK_API_KEY，再运行 `node start-local.mjs --test-key-file ABSOLUTE_IGNORED_TEST_FILE`。不要把Key写进命令行或发给他人；调用有API用量，公开上线须另行授权正式配置。
6. 生成 → 修改确认 → 记录 → 复盘 → 查看引用 → 反馈回执。录屏使用虚构数据时标清“虚构验收”，不作为用户效果。

关闭后服务停止，存档在data/保留；不要删除该目录。localhost仅当前电脑可访问，不能作为公开投稿网址。正式部署和备份见独立包deploy/DEPLOY.md。

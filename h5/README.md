# H5 参赛试用版

本目录是现有 `site/` 的独立运行适配，不覆盖已发布的 Sites。用 Node.js 24、Next.js、SQLite 和私有照片目录运行，保留已有目标—行动—记录—AI复盘—反馈及2D角色规则。原始 Sites 版本来源清单仍是历史证据，不代表 H5 与其逐文件一致。

## 范围

- `/`：移动端作品首页，固定演示和受邀试用两个入口；真实AI开关状态明确显示。
- `/demo`：原有固定虚构流程，无模型调用或个人存档。
- `/access`：每位试用者单独的邀请码，无需 ChatGPT；邀请码是账户凭据，不能在公开投稿正文、截图或源码中发布。
- `/play`：已有产品界面，个人存档、照片、AI与反馈使用独立身份。
- `/about`：实际数据存储、额度、旧数据边界与试用说明。

首版不做支付宝小程序、支付宝授权、支付订阅或开放注册。邀请制适合小规模试用；并不代表已获得赛事评审访问安排。正式投稿前需在报名入口确认评委如何取得专属试用凭据，不能让所有人共用同一个私有账户。没有邀请码也可先进入明确标注的演示。

## 导出与运行

如果收到的是 `life-rpg-h5-submission-v0.1.zip`，解压后进入 `life-rpg-h5/`，直接从安装依赖开始；下面的导出步骤仅用于完整GitHub仓库。

在仓库根目录运行：

```text
node scripts/prepare-h5.mjs
```

输出 `outputs/h5-submission/`。只从 Git 跟踪的应用源码及 `h5/overlay` 白名单导出，不复制 Sites `.dev.vars`、环境、数据库、依赖或构建产物。生成目录与实际数据被 Git 忽略。不要手改生成目录作为长期源码，变更应保存在适配层或原有源码。

进入输出目录，使用 Node.js 24：

```text
corepack pnpm install --frozen-lockfile
```

将 `runtime.env.example` 复制为 `.env.local`，本地地址设置为 `APP_ORIGIN=http://127.0.0.1:3000`。配置正式部署时使用实际 HTTPS origin，不含路径或末尾斜杠，并将 `H5_DATA_DIR` 设为绝对持久目录。CLI 读取 `.env.local`；服务的环境变量可由受保护的进程配置提供。

```text
corepack pnpm h5:init
corepack pnpm h5:invite --out ABSOLUTE_PRIVATE_FILE
corepack pnpm build
corepack pnpm start
```

`ABSOLUTE_PRIVATE_FILE` 必须改为已有私有目录内的新文件绝对路径。命令只打印账户ID，不把邀请码写到终端日志。请通过合适的私密渠道单独交付给本人，禁止提交文件到Git。每位试用者单独创建；同一邀请码可在新设备找回同一账户，不能共用。停用命令为 `corepack pnpm h5:revoke ACCOUNT_ID`，同时撤销全部现有会话，保留存档。

开发可用 `corepack pnpm dev`。服务默认仅监听127.0.0.1，公网由HTTPS反向代理接入。初始化只接受空数据库或本适配器带迁移日志的数据库，校验已应用SQL哈希；不接受直接覆盖旧D1数据库文件。更新前保留一致性备份，不能改写已应用SQL。

## 独立部署条件

需要支持 Node.js 24 进程和持久磁盘的主机/容器平台；纯静态空间不能运行本版本。单实例运行，不把SQLite放网络共享盘。应用启动命令在服务管理器中执行，崩溃重启、HTTPS、访问日志、磁盘告警和备份由部署环境落实。

反向代理保留正确Host及协议，`APP_ORIGIN` 必须等于浏览器公开地址。数据库和照片目录不能放入 `public/` 或静态映射；只有应用私有API能读取。生产HTTPS下会话cookie为HttpOnly、Secure、SameSite=Lax；数据库只保存邀请码/会话Token的哈希。会话默认7天，账号可撤销；不信任公网传入的Sites身份头。浏览器重新登录/退出时清理本应用临时输入，避免在共用设备跨账户保留。

照片保持每张2MB、每用户500张的现有上限，实际容量、总磁盘阈值及备份容量需部署时按预算调整。SQLite WAL一致性备份应使用SQLite备份能力或停机后整体备份，不能只复制正在写入的主数据库文件。照片及数据库须一起制定恢复方案；源码归档不等于数据备份。

大陆托管上线前需核验域名、ICP备案与主体/服务内容适用性；具体资源未采购，当前没有公网地址。域名、服务器、模型和备份是不同费用。没有自动迁移旧Sites账号：旧数据保留在原环境，后续迁移必须验证归属并提供兼容/回滚，不按昵称匹配。

## AI和费用边界

默认 `AI_ENABLED=false`，导出包不包含任何Key。只有维护者取得正式用途授权后，在服务端配置 `DEEPSEEK_API_KEY` 并启用AI。现有测试凭据不得自动复制或公开。启用前核对模型名、余额和当前单价。

沿用现有服务端DeepSeek实现及确认机制；AI本身不能修改成长奖励。独立版本默认每用户5次/天、全站30次/天，失败尝试计数。数据库原子预留次数覆盖并发请求；次数限制不等于人民币预算上限，用量账单、余额告警及停止开关仍由维护者管理，首版不承诺财务额度硬封顶。

## 反馈与投稿

应用内反馈仍按用户隔离。维护者在部署主机运行 `corepack pnpm h5:feedback --out ABSOLUTE_PRIVATE_FILE` 导出最近90天反馈；导出是私有内容，不纳入源码/投稿压缩包。登录丢失的用户先联系邀请来源。全量数据删除仍为核对账号后的维护流程，自动找回与完整删除后台尚未实现。

投稿需要公网HTTPS链接、可实际交互的真实AI流程、16:9封面、简介与演示说明。ZIP源码可作为补充交付，不能把本地编译成功等同于完成公开访问或真实评委体验。正式材料基于 `docs/SUBMISSION_READY.md` 更新，须写明H5、独立登录、真实托管地区、当前功能和未接入能力。当前独立版尚未公网部署、接入正式Key或正式提交。

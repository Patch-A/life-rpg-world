# v2 概念稿核对 · 2026-11-01

核对对象：`docs/art/recordkeeper-concept-v2/` 三个 PNG。
核对方式：逐像素量（alpha 通道、色相分布、内容包围盒）+ 在真实尺寸下与 `assistant-scene` 合成后截图。
尺度覆盖 56px（手机陪伴条）、40px（备选）、230px（桌面场景）、以及 dpr=3、dpr=4 的真机像素密度。

**这不是已验收的正式素材。** 下面的「通过」只代表概念稿满足或接近需求单的硬约束，
不代表已接入应用、也不代表真机上看过。

## 二、必须改：枝端像手

`01` 主稿里两根短枝在树肩高度左右对称外翘，**枝端各带一簇叶子**（约 `x390-810, y700-900` 区域）。

实测：350% 放大下读作「戴绿手套的手」；缩到 56px 后读作「在挥手的两只手」，
比手上那两根真正的枝条还显眼。

需求单第一条就是「不长人手」。以当前形态算不上违反（没有手指、没有手掌结构），
但这是全图唯一一处会让人第一眼质疑的地方，且它是**对称 + 肩高 + 末端有彩色块**这三个
「像手」的特征同时成立才产生的。

**改法（最小）**：枝端叶簇去掉，或把短枝改成水平外伸、末端不留叶。其余全部不动。

## 三、接入时会撞的两个问题

### ① 五状态表切不开

`03-recordkeeper-mint-five-states.png` 看似五棵树并排，实际是**连在一起**的：

| 分界 | 该列最小 alpha |
|---|---|
| 树 1–2 | **251** |
| 树 2–3 | **250** |
| 树 3–4 | **252** |
| 树 4–5 | 9（唯一干净断开） |
| 画布左右留白 | 7px / 20px |

也就是说树冠边缘互相贴住了，**不能自动切片**。要么让 GPT 按「等画布、留白间隔」重出，
要么手工抠。

另：五棵树底边对齐良好（均为距底 45px），但 `listening` 那片竖叶让 3 号高 621px，
其余为 523–573px。放进等高盒子里 `contain` 会让另外四棵一起缩小。

### ② thinking 和 idle 在 56px 下分不出来

缩到 56px 后两张几乎重合。而 `thinking`（等模型回复）是**停留时间最长**的状态 ——
这个差异等于白做。

### ③ 自带土包 vs 场景已有台座

`assistant-scene.css` 里已画了 `.assistant-scene__pedestal` 椭圆台座。
合成实测：树踩土包、土包浮在椭圆台座上，中间空一段，成了两层底座。

**建议**：去掉 CSS 那个椭圆（土包本身就是地面，比椭圆自然），而不是改图。

## 四、判定为可接受、不需要返工

**风格和 `character-lab` 不是同一个游戏。** 并排看差异明显：
角色那套偏写实冷调，这棵树是高饱和厚涂 Q 版。但两者同屏机会很少
（树人只出现在首页 `today` 场景，角色在世界页 `world`），且「卡通树人」本来就是
2026-10-31 拍板的方向。**判定可接受。**

**idle 的年轮偏亮。** 年轮区平均 RGB (236,187,122)、亮度峰值 245，是深色场景里
整棵树最亮的一块。玩 `thinking` 时恰到好处，平时该暗下去。
交给 CSS 调，不用重新出图。

## 五、生产规格上的缺口

| 项 | 现状 | 需求单要求 |
|---|---|---|
| 主稿体积 | 1.35 MB | ≤200KB |
| 五状态表体积 | 1.67 MB | ≤200KB |
| 尺寸 | 1254×1254 / 2146×733 | 2048×2048 |

`02-...-56px.png`（56×56，内容 48×56，6.7KB）直缩质量合格，但它是**测试图**、
不是上架素材：dpr3 真机上需要 **168px 宽**才清晰。已实测 168px 导数与 56px 放大版
差别很大（56px 放大后叶片糊成一团）。

体积不是阻塞项 —— 概念稿在 `docs/` 下，不随包发布。转 512px webp q90 为 **61KB**，
完全够用。

## 六、两条路

| | 做法 | 代价 | 风险 |
|---|---|---|---|
| **A（推荐）** | 只用主稿静态图，`idle/speaking/thinking` 全部由 CSS 做（呼吸、叶隙透光、年轮脉动），只补一张 `listening` 单图 | 需 GPT 补 1 张 | 状态差异靠 CSS 在 56px 上是否看得出来，**未验证** |
| B | 让 GPT 按「等画布、留白间隔、枝端不带叶」重出五张，切干净 | 需重出 1 张五状态表 | 重出可能引入新问题，且要重新核对 |

推荐 A 的理由：`thinking` 和 `idle` 在 56px 下本来就分不出来，逼真图上去也白费；
CSS 做的呼吸和年轮脉动在手机上反而比换图更明显。但 **A 的「CSS 在 56px 上够不够明显」是未验证的**，
接进场景后必须按 `feedback-verify-real-entry` 在真机上确认。

## 三、踩过的坑

1. **dev server 端口变了。** 记忆里写的是 `127.0.0.1:5174`，这次实际起在 **5173**
   （`npm run dev` 输出 `Local: http://127.0.0.1:5173/`）。别再照着 5174 写死；
   启动后读日志确认，或看输出。
2. **紫色判据写成 `===0` 会误杀正常素材。** 抗锯齿边缘本来就会出几个孤立像素。
   任何「绝对为零」的像素判据都要先量一遍基线再定。
3. **ESLint 的 `react-hooks/set-state-in-effect` 是 error 不是 warning。**
   `useEffect(()=>{setX(...)},[])` 这种「挂载后同步一次」的老写法在这里直接红。
   读浏览器能力用 `useSyncExternalStore(fn, getSnapshot, getServerSnapshot)`。
4. **`useSyncExternalStore` 的 `getSnapshot` 必须返回稳定引用。** 每次返回新对象会无限重渲染，
   所以 `voiceStatus()` 内部做了缓存。这条下次再写类似东西时同样适用。

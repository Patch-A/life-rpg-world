# 首版投稿材料草案

状态：2026-10-11草案。下列拟实现功能通过 `SUBMISSION_PLAN.md` 验收前，不能作为已完成功能提交。

## 名称与简介

拟用名称：人生RPG · 成长星球

拟用简介：把想做的事变成今天做得动的小任务。AI根据目标、时间和障碍给出行动建议；用户确认并记录真实进展，让成长积累在自己的星球上，再根据记录调整下一步。

目标用户：有学习、创作或个人项目目标，需要降低开始负担、看见日常积累的成年用户。首版以文字记录与自主确认支持个人使用。

## AI必要性与实际边界

验收后可使用的说明：DeepSeek根据用户选择的目标、成功标准、当日可用时间和障碍生成候选动作；根据用户选择的实际记录生成简短复盘及下一步建议。候选动作允许编辑、拒绝，确认后保存。经验、升级、奖励及存档权限由确定性规则处理。

不能写成：自动证明用户完成、自动规划所有人生事项、已经接入支付宝账单/运动数据、已经发布支付宝小程序、自动获得阿宝用户分发。

## 演示脚本

1. 选择虚构样例“完成一篇文章”，填入每天20分钟及“还不知道如何开头”。
2. 展示AI候选动作及理由，改小其中一项并确认。
3. 完成动作后填写文字记录；示例记录明确标注虚构。
4. 展示成长与存档变化，刷新证明记录保存。
5. 触发短复盘，展示引用的记录及建议；确认下一项行动。
6. 展示反馈入口及AI失败时的手动路径。

# 国内登录阻塞与部署纠正

日期：2026-10-13。状态：国内完整登录阻塞已确认，迁移方案待实施。

## 已确认事实

- 用户实际登录截图显示OpenAI认证页面返回 `unsupported_country_region_territory`，说明登录服务拒绝当前地区；本轮没有检测用户具体网络出口地点。
- 本轮读取的官方ChatGPT支持列表没有中国大陆，不能把ChatGPT账号登录当成面向大陆用户稳定、受支持的产品登录方案。
- 当前第12版由OpenAI Sites托管，域名为 `life-rpg-world.docileape4.chatgpt.site`。服务端为Cloudflare Workers，D1保存结构化记录，R2保存照片。具体计算与数据物理区域本轮未获得，不能声称已经部署在中国大陆或某个确定国家。
- 个人接口依赖Sites可信注入的登录身份；DeepSeek只承担模型调用，更换模型配置不能改变登录依赖。
- GitHub是源码归档。公开入口、匿名演示及私人API拒绝匿名访问，不证明大陆用户能完成登录和使用真实AI/个人存档。
- 用户确认目前没有服务器/云托管及域名。现有Sites资源不是用户自行管理的国内服务器。

## 修正发布结论

第12版已经实现并发布AI行动流程；匿名演示及权限边界已核验。但是国内完整登录未通过，当前URL不能描述为已具备大陆目标用户完整体验能力。

上一轮将国内登录留为后续验收，优先级不合理。对面向支付宝及国内用户的作品，这项应成为正式投稿和试用前的门槛。保留 `submission-v0.1` 为历史发布快照，不移动标签掩盖阻塞；当前状态以本记录及 `RELEASE_STATUS.md` 为准。

## 建议路线（实施意见）

1. 复用现有UI、目标/记录规则和DeepSeek适配，准备独立Web部署。现有Sites暂作演示入口。
2. 首批少量用户可采用本项目独立的邀请制账号和密码，由服务器验证会话、隔离用户，无需ChatGPT账号。短信登录涉及短信服务和费用，选定资源后再比较。不能让所有访客共享一个生产身份。
3. 适配当前数据库、照片存储和身份的平台绑定。托管资源、服务器区域、域名、费用及相关备案要求需在采购前核验；不能未经目标网络验证就承诺国内可达。
4. 明确旧Sites用户ID与新账号的关联，保留目标、记录、照片引用、生日、奖励与历史。不能清空旧数据或仅凭昵称合并身份；私人数据和迁移凭据不进入GitHub。
5. 后续小程序再接入经过独立验证的支付宝身份，网页阶段不依赖尚未取得的平台权限。
